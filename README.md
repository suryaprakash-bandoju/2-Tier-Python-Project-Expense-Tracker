# Expense Tracker

A simple web-based expense tracking application built with Python and Flask.

## Features

- Add expenses
- View expenses
- Delete expenses
- Filter expenses by category
- Calculate total expenses
- SQLite database
- Responsive web interface

## Technologies

- Python
- Flask
- SQLite
- HTML
- CSS
